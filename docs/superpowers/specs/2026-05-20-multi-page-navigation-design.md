# AiControlAll — 多页面导航与默认页设计规格

> 状态：头脑风暴完成，待用户审查
> 日期：2026-05-20

---

## 1. 概述

将 AiControlAll Android 应用从单聊天界面（MainActivity + 侧滑面板 + SettingsActivity）重构为完整的六页面导航系统，并新增科幻风 AI 默认页作为应用主页。

## 2. 页面架构

### 2.1 页面清单

| 序号 | 页面 | 用途 | 进入方式 |
|------|------|------|----------|
| 0 | 默认页 | AI 等待态，语音/设备交互入口 | 应用启动 |
| 1 | 聊天 | 纯文字对话 | 菜单 |
| 2 | 历史 | 历史会话管理 | 菜单 |
| 3 | 记忆 | 事实记忆 CRUD | 菜单 |
| 4 | 工具 | MCP 工具注册/状态 | 菜单 |
| 5 | 技能 | 技能库管理 | 菜单 |
| 6 | 设备 | 硬件能力抽象层 | 菜单 |
| 7 | 设置 | API 配置 / 系统开关 | 菜单 |

### 2.2 导航方案

**方案 A：右上角折叠菜单**（已选定）

- 默认页和聊天页是两种并列的主模式，不互相嵌套
- 所有二级页面通过右上角 ☰ 汉堡菜单从右侧滑出抽屉进入
- 二级页面点 ← 返回回到默认页（而非聊天页——聊天也是菜单中的一项）
- 菜单结构：
  - 核心功能：聊天 / 历史 / 记忆 / 工具 / 技能
  - 分割线
  - 系统管理：设备 / 设置
- 每个菜单项带实时计数徽章

### 2.3 导航状态流转

```
[应用启动] → 默认页
    │
    ├── ☰ → 抽屉菜单
    │       ├── 聊天      → 聊天页
    │       ├── 历史      → 历史页
    │       ├── 记忆      → 记忆页
    │       ├── 工具      → 工具页
    │       ├── 技能      → 技能页
    │       ├── 设备      → 设备页
    │       └── 设置      → 设置页
    │
    └── 语音唤醒 → 默认页内交互（不跳转）
```

二级页面 ← 返回 → 默认页

## 3. 默认页设计

### 3.1 视觉层次

```
┌─────────────────────────────┐
│  AiControlAll    M:12 [☰]   │
│                             │
│     ○  ○  ○   ← layer 2    │
│   ○ (设备) ○   小星球       │
│  ○    ○     ○   漂浮动画    │
│       ╭──────╮              │
│  ♪   │  ●   │  ♫ ← layer 1 │
│ ♩    │ AI   │   ♬  主星球   │
│  ♫   ╰──────╯  ♩  带星环    │
│       ♪    ♬    音符跳动    │
│                             │
│   ▎▌█▌▎  ← 声波动画         │
│   正在聆听…                  │
└─────────────────────────────┘
```

### 3.2 元素说明

#### Layer 1 — 主星球（底层 z-index:1）

- **星球本体**：180px 直径圆，深蓝黑径向渐变模拟气态行星表面，内发光（#00D4FF 晕染），有水平色带条纹
- **辉光环**：200px 直径，4 秒周期脉冲发光，颜色在 #00D4FF11 ↔ #00D4FF33 之间渐变
- **星环**：260×70px 椭圆，倾斜透视效果（rotateX 约 70°），20 秒旋转一周，1.5px 宽半透明边框
- **呼吸动画**：星球 2 秒周期 scale(1) ↔ scale(1.06) 脉动，辉光同步增强
- **音符**：8 个音符 ♪♫♩♬ 散布在星环轨道附近，各独立周期（2.5~3.8s）上下浮动 + 透明度闪烁
- **颜色**：青色 #00D4FF、绿色 #06D6A0、灰白 #8899aa 三种音符混合
- **语音激活**：星球脉动加速，星环旋转加速，音符跳动频率翻倍
- **处理中**：星球表面流光扫过效果（后续实现）

#### Layer 2 — 小星球（上层 z-index:2）

- **尺寸**：52px 直径，约为主星球的 29%
- **视觉**：深色径向渐变圆 + 设备图标 + 状态色点 + 标签文字（10px 截断）
- **在线设备**：完整不透明，绿色状态点 + 对应辉光色边框
- **离线/未连设备**：opacity 0.6，橙色状态点，辉光暗淡
- **浮动动画**：每个小星球独立漂浮周期（6~11s 不等），x/y 方向小幅度余弦偏移（±4~8px），错落延迟避免同步
- **位置分布**：8 个小星球散布在主星球周围，不重叠
- **交互**：点击弹出详情浮层（类型/状态/详情/MCP 工具），点击其他区域关闭

#### 环境元素

- **星空背景**：10+ 颗随机散布的小星点，各独立闪烁周期
- **声波动画**：5 根竖直柱状条，高度 8/16/24/16/8px，0.6s 跳变动画
- **状态文字**：底部居中 "正在聆听…"，带三个闪烁点
- **状态切换**：空闲=正在聆听 / 识别中=处理中… / 执行中=执行…(工具名)

### 3.3 语音交互流程

1. 唤醒词触发 → 主星球脉动加速 + 星环加速 → 声波动画激活
2. 用户说话 → 音符跳动频率翻倍 → 声波振幅变化
3. 识别完成 → 主星球闪一下（瞬间 scale 1.1 + 辉光高亮）→ 状态切换为"处理中…"
4. LLM 处理 → 星球表面流光
5. 工具调用 → 相关小星球高亮闪烁
6. 结果 → TTS 播报 + 状态回到"正在聆听…"

## 4. 二级页面设计

### 4.1 通用结构

所有二级页面（历史/记忆/工具/技能/设备/设置）共享同一布局模板：

```
┌─────────────────────────┐
│ ← 标题            N 个  │  ← 顶栏：返回 + 标题 + 计数
├─────────────────────────┤
│ 🔍 搜索…                │  ← 搜索框（设置页除外）
├─────────────────────────┤
│ ▶ 项目一       [标签]   │  ← 可展开项目列表
│   └ 展开详情 + 操作按钮  │
│ ▶ 项目二       [标签]   │
│ …                       │
└─────────────────────────┘
```

- 返回箭头 ← 回到默认页
- 搜索框即时过滤列表
- 每项可展开/折叠，展开后显示完整字段 + 操作按钮

### 4.2 聊天页

- 与当前 MainActivity 聊天区相同
- 纯文字输入输出
- 底部输入框 + 发送按钮
- 无语音交互（语音走默认页）

### 4.3 历史页

- 展开字段：会话 ID、摘要
- 操作：继续对话、删除

### 4.4 记忆页

- 展开字段：目标分类、标签、完整内容
- 操作：编辑、删除
- 底部"加载更多"触发分页

### 4.5 工具页

- 展开字段：接口、权限、参数、依赖
- 状态标签：已注册（绿色）、计划中（黄色）
- 已注册工具：测试按钮

### 4.6 技能页

- 展开字段：版本、使用次数、步骤、陷阱
- 置信度标签：≥70% 绿色、40-70% 白色、<40% 黄色
- 操作：编辑、禁用/删除

### 4.7 设备页

设备页展示手机硬件能力抽象层。每项是一个硬件能力：

| 设备 | 类型 | 输入/输出 | 状态 |
|------|------|-----------|------|
| 摄像头 | 内置 | 输入 | 待机 |
| 麦克风 | 内置 | 输入 | 待机 |
| 扬声器 | 内置 | 输出 | 空闲 |
| 屏幕 | 内置 | 输出 | 开启 |
| GPS | 内置 | 输入 | 待机 |
| 运动传感器 | 内置 | 输入 | 采集中 |
| 蓝牙耳机 | 外设 | 输入+输出 | 未连接 |
| 蓝牙手表 | 外设 | 输入 | 未连接 |

- 展开字段：类型、能力清单、实时状态、采集的数据字段、暴露的 MCP 工具
- MCP 是设备驱动层向上对 AI 暴露的调用协议，不是设备本身
- 已实现 MCP 工具标绿，计划中标黄

### 4.8 设置页

- API 配置：API Key、模型、Base URL
- 系统：进化引擎（即时切换开关，无需保存按钮）、配置文件路径
- 关于：数据库大小、版本号、重置按钮
- 分区展示，section 标签分组

## 5. 配色与风格

- 背景：#0A0E17（深蓝黑底）
- 卡片/组件：#1A2332
- 主色：#00D4FF（青色，标题/高亮/活跃态）
- 辅色：#06D6A0（绿色，在线/成功/计数）
- 警告：#f0a030（离线/计划中）
- 危险：#ff5c5c（删除/禁用）
- 文字主：#e0e6f0
- 文字辅：#5a6a80
- 字体：monospace（SF Mono / Fira Code）
- 圆角：8px（按钮/卡片）、20px（输入框/药品）

## 6. 技术要点

- Activity 架构：单个 MainActivity 使用 Fragment 或 View 切换管理所有页面，避免多个 Activity 跳转
- 默认页动画：Canvas 或 Lottie 实现星球/星环/音符动画
- 语音唤醒：Android SpeechRecognizer 或第三方唤醒词 SDK（如 Porcupine）
- 页面状态保持：Fragment 或 ViewModel 保持各页面滚动位置和数据
- 菜单抽屉：DrawerLayout（右侧滑出）或自定义 View + TranslationX 动画
